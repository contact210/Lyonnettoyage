# Escrever para a administração ou a escola

## Passos
1. **Reunir as informações** :
   - destinatário ;
   - objet (assunto) ;
   - fatos, com as datas ;
   - pedido exato ;
   - documentos anexos ;
   - canal de envio.

   Perguntar só o que faltar.
2. **Escolher o canal** :
   - messagerie de caf.fr ou ameli.fr : rastreável, ótimo para pedidos simples ;
   - **recommandé avec AR** : para recurso, résiliation ou relance após prazo ;
   - Pronote ou carnet de correspondance : para o collège ; cahier de liaison ou e-mail : para a école.
3. **Redação em francês** : uma página no máximo, vouvoiement, tom factual. Sem emoção nem justificativas longas.
4. Logo abaixo, a **"Tradução para conferir (PT)"**, fiel ao texto.
5. **Checklist antes de enviar** : anexos completos, cópia guardada, prazo respeitado, canal certo.
6. Se o Gmail estiver conectado e o usuário pedir : criar um **rascunho**, não enviar. Mostrar e pedir confirmação.

## Modelo de carta
```
[Prénom NOM]
[Adresse]
[Téléphone – e-mail]

[Organisme – service]
[Adresse]

À Lyon, le [date]

Objet : [objet précis]
Réf. : [n° allocataire / n° de sécurité sociale / n° de dossier – à compléter par vous]

Madame, Monsieur,

[Fatos : 1 a 3 frases, com as datas.]
[Pedido : "Je vous prie de bien vouloir …"]
[Anexos : "Vous trouverez ci-joint …"]

Je vous prie d'agréer, Madame, Monsieur, l'expression de mes salutations distinguées.

[Signature]
PJ : [liste]
```
Deixar as referências sensíveis como **placeholders** : o usuário preenche, nada é gravado no repositório.

## Frases-chave por situação
| Situação | Frase principal |
|----------|-----------------|
| Changement de situation (CAF, CPAM) | « Je vous informe que, depuis le [date], [changement]. » |
| Demande d'attestation | « Je vous remercie de bien vouloir me transmettre une attestation de [type]. » |
| Relance | « Sans réponse à ma demande du [date], je me permets de vous relancer. » |
| Recours CRA (CAF, CPAM), 2 meses | « Je conteste la décision du [date] et saisis la Commission de recours amiable. En effet, … » |
| Remise de dette (indu CAF) | « Ma situation financière ne me permet pas de rembourser cet indu ; je sollicite une remise totale ou partielle de dette, ou à défaut un échéancier. » |
| RAPO MDPH, 2 meses | « Je forme un recours administratif préalable obligatoire contre la décision de la CDAPH du [date]. » |
| Relance MDPH (mais de 4 meses) | « Mon dossier déposé le [date] n'a pas reçu de réponse ; je vous remercie de m'indiquer où en est son instruction. » |
| Résiliation mutuelle (contrato com mais de 1 ano) | « Je résilie mon contrat n° [ ] conformément à l'article L. 221-10-2 du Code de la mutualité (résiliation infra-annuelle). » Se não for uma mutuelle, verificar o código aplicável : Code des assurances ou Code de la sécurité sociale. |
| Déclaration de sinistre (prévoyance) | « Je vous déclare [arrêt de travail / invalidité / décès] survenu le [date] au titre du contrat n° [ ]. » |
| Ausência na escola ou no collège | « [Prénom] a été absent(e) le [date] pour raison [médicale / familiale]. » |
| Reunião com professor | « Je souhaiterais vous rencontrer au sujet de [Prénom]. Seriez-vous disponible [créneaux] ? » |
| Dérogation de secteur (collège) | « Je sollicite une dérogation pour l'affectation de mon enfant au collège [ ], pour le motif suivant : [ ]. » |

## Mensagens para a escola (curtas)
```
Bonjour Madame / Monsieur [Nom],
[1 a 3 frases.]
Cordialement,
[Prénom Nom], parent de [Prénom], classe de [classe]
```
